# BlezeX Career Accelerator Program: landing page

Vite + React + TypeScript + Tailwind CSS + Framer Motion + Lucide.

## Run in VS Code
```
npm install
npm run dev
```
Open the URL shown in the terminal (usually http://localhost:5173).

## Build
```
npm run build
```

## Edit content
All copy is in `src/data.ts`. Colors and fonts are in `tailwind.config.js`.
The logo is `public/logo.jpeg`. "Download Brochure" opens the print dialog; choose "Save as PDF".
